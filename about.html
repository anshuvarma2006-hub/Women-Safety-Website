About the Project

Women Safety Website

A web-based academic project designed to bring important safety-support features together in one simple interface.

📖 About Women Safety Website

The Women Safety Website is an academic mini project developed to demonstrate how web technologies can be used to organize safety-related features in a single platform.

The system provides features such as emergency support, trusted contacts, location support, incident reporting and safety information.

The current version is a frontend/demo implementation developed using HTML, CSS and JavaScript.

🎯 Project Objectives

  • Provide a simple and user-friendly safety interface.
  • Provide quick access to emergency support features.
  • Allow users to maintain trusted contact information for demonstration.
  • Demonstrate browser-based location support.
  • Provide a structured incident-reporting interface.
  • Provide useful general safety information.

⭐ Main Features

🚨

Emergency Support

Provides access to emergency-related support features.

👥

Trusted Contacts

Allows demonstration contacts to be added and managed.

📍

Location Support

Uses browser geolocation to display location coordinates with permission.

📝

Incident Reporting

Provides a form for recording incident information.

🛡️

Safety Tips

Provides general personal, digital and travel safety information.

📱

Responsive Design

Designed to work across desktop and mobile screen sizes.

⚠️ Academic Project / Demo

This website is an academic demonstration. It does not automatically contact police, emergency services or other authorities. A production system would require secure backend services, database integration, authentication, privacy controls and authorized emergency-service integration.
